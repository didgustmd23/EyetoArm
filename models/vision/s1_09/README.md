- **운영 미채택:** 기본 모델은 S1-08입니다. 교체는 A가 정합니다.

- **벨트 이동 중 집기:** 검증하지 않았습니다(C-12).

## 실행

가상환경·ROS 환경을 준비하고 Gazebo 링크 카메라를 실행한 뒤 **저장소 루트**에서 실행합니다.

```bash
export YOLO_AUTOINSTALL=false
export YOLO_OFFLINE=1
PYTHONPATH="src${PYTHONPATH:+:$PYTHONPATH}" python scripts/run_pipeline.py --ros-link --detector ai \
  --ai-config config/vision/ai_s1_09_axis_m2_viewbias.json
```

시작할 때 시야 보정 설정을 B 규격(`config/calibration/part_specs.json`)과 대조합니다. 종류 이름, 라벨, 평면 높이가 맞지 않으면 실행을 시작하지 않습니다. 이때는 k를 다시 맞춰야 합니다.

원본 학습 가중치는 저장소 밖(학습 PC outputs, A 작업 기록 #278)에 그대로 보존합니다. 이 폴더에는 선택한 best.pt만 넣습니다.

분할 결과는 표시용이며, 계산용 윗면 윤곽이나 유효한 로봇 목표가 아닙니다. 신뢰도 0.05는 현재 선택값이며, 오검출이 0이라거나 정답 확률이라는 뜻이 아닙니다.
