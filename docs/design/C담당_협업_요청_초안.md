- **산출물:** 시각 필드·세대 변경·무효화·replay 규칙표와 확인 사례.

- **산출물:** 작업·로봇 프레임, 파지 오프셋, 작업영역·경로 기준 및 기대 변환 결과가 포함된 시험값.

### CB-03 움직이는 벨트 분류 ROS 액션 계약

- **배경:** 정상 집기는 움직이는 벨트에서 수행합니다. C 회신 기준 입력 표현은 작업 좌표계 기준 위치 `mm`와 방향 쿼터니언 `[x, y, z, w]`이며, B 상세설계의 위치 `m` 표기와 불일치합니다. B는 관측 위치·촬영 시각·벨트 속도와 방향을 보내고, C가 예상 집기 시점 목표를 계산하는 안에 C가 회신했습니다.
- **요청:** 이 입력 표현을 B 상세설계와 액션 정의에 맞추고, 액션 이름·메시지 패키지·goal/feedback/result/cancel 필드·의미·상태, 중복 goal·클라이언트 단절·C 재시작 후 기존 goal 조회와 재전송 방지 규칙을 합의하고 싶습니다. START/STOP에 따른 목표 송신 활성화와 작업 상태·결과 전달도 포함해 주세요.
- **산출물:** 움직이는 벨트 기준 액션 계약표, 예시 goal·feedback·result, 취소·중복·단절·재시작 처리 규칙.
