# D 담당 협업 요청 초안 (A·B·C)

문서 버전 0.1 · D 검토 초안 · 2026-11-16 · **미발송** · 검토 기준 HEAD `c8b992f506097666de807e4150f0924113ccabc5`

이 문서는 D가 팀에 전달할 요청 초안입니다. 기한은 합의 전 제안이며 문서 작성은 상대 승인·실제 발송·시험 완료가 아닙니다. 관련 근거: [A 요청](A담당_협업_요청_초안.md), [B 요청](B담당_협업_요청_초안.md), [C 요청](C담당_협업_요청_초안.md), [D 상세설계](D담당_GUI_TCP_상세설계.md), [TCP 명세](../protocol/TCP_프로토콜_명세서.md).

Windows는 D GUI 구현 환경, Ubuntu는 팀원 코드 수신 환경입니다. Windows 미커밋 구현을 Ubuntu에 직접 복사하지 않습니다. D 5일차는 Windows 내부 모의 구현·회귀와 정적 리뷰가 완료된 상태이며, 실제 C 분류·도착 및 정식 3영상 통합은 미완료입니다. 모의 사건·집계 규칙을 실제 계약으로 강제하지 않습니다.

정상 분류는 벨트를 멈추지 않고 이동 중 집기합니다. 비상·이상 정지 뒤 재시작할 때 이전 목표·관측을 폐기하고 새 관측을 사용합니다. 되감기와 세대 변경의 무효화 기준도 별도 확인합니다.

## A에게 요청

### DA-01 표시 결과·무효화와 공통 자료형 — P1

- **필요사항:** C를 거쳐 D가 받는 영상과 결과·무효화의 소스·프레임·세대·시각 대응, 필수/None 허용 필드, 유효 시간·지연 폐기와 재접속 시 복구 기준을 A·C와 확인합니다. 프레임 없는 오류에 가짜 ID를 만들지 않습니다. 다른 시각 기준을 직접 비교하지 않습니다.
- **요청 산출물:** 공통형 변경 예정·미구현 관측/결과/사건형 정의 시점, 필드·단위·무효 사유와 같은 관측의 예시, 결과·무효화 순서 및 세대 변경·되감기/replay 사례. **제안 기한:** 11/17 초안, 11/20 첫 통합 전 합의 목표.
- **D 제공:** 화면 필드·미수신 표시와 소비 예시, 프레임 불일치·단절 시 처리 초안.
- **미회신 영향:** 저장/모의 예제만으로 소비 준비하며 실제 결과 정합과 표시 연결은 미완료입니다.

### DA-02 A→C 내부 전달 — P1

- **필요사항:** A와 C는 같은 프로세스에서 객체·내부 대기열로 표시 데이터를 전달하는 방향입니다. D는 소비 영향 확인을 위해 인터페이스를 요청하며 내부 구현을 지정하지 않습니다.
- **요청 산출물:** 객체·호출·소유권·기동/종료와 영상 최신 우선, 결과·무효화 순서 보존 및 적체·폐기 정책을 C와 협의한 초안. **제안 기한:** 11/17.
- **D 제공:** 표시 경로에서 필요한 순서·식별자·장애 표시 요구.
- **미회신 영향:** A→C 세부 계약과 C→D 실제 연계 정합을 확정할 수 없습니다.

### DA-03 통신 시험용 클라이언트 — P2

- **필요사항:** A의 WSL 시험 도구에서 GUI와 분리된 TCP 클라이언트 재사용을 확인합니다. 현재 `src/eyetoarm/tcp/client.py`의 `TcpClient(config, log, notify)`는 동기 `connect()`·`snapshot()`, 비동기 `disconnect()`·`query_ready()`·`execute()`·`cancel()`을 제공합니다. 도구가 asyncio 루프를 소유해 루프 안에서 connect하고 종료 시 disconnect를 기다려야 합니다.
- **요청 산출물:** A 시험 도구의 실행 조건·사용 API·주소·예제와 변경 알림 방식. **제안 기한:** 11/18 목표.
- **D 제공:** 현재 API·TCP 1.1·GUI 환경 파일의 Python 3.12 기준과 기록 설명. `EventLog(path | None, keep=500)`은 지정 시 JSONL을 기록하며 정기 준비 조회는 파일에 남기고 최근 목록에서 제외합니다. raw는 UTF-8 대체 디코딩 및 끝 LF 제거 텍스트이며 원시 바이트 완전 보존이 아닙니다. GUI 화면 기록과 분리합니다.
- **미회신 영향:** API 안정 범위·A 환경에서의 호환과 주소는 미확인이므로 실제 시험 도구 연결을 완료로 볼 수 없습니다.

## B에게 요청

### DB-01 규격·측정값과 중심점 영상 — P1

- **필요사항:** D 화면에 표시할 규격·측정 결과를 실제 판정과 구분 없이 추정하지 않도록 의미와 유효 조건을 확인합니다. 길이·좌표는 단위와 D의 표시/TCP 경계에서 mm 변환 1회 여부를 확인합니다. 각도는 deg이며 너트 `theta_valid=false`의 방향 없음 의미를 확인합니다.
- **요청 산출물:** 규격별 판정 기준, 보정 ID, 실패·미판정 사유 및 단위가 명시된 표시 입력 예시. `center` 주석 영상의 원본 프레임 키와 동일 관측의 결과 JSON 표본, C에 입력을 전달할 조건. **제안 기한:** 11/17.
- **D 제공:** 표시 필드·미수신/무효 표기와 모의 사건 예시, 단위 및 프레임 대응 확인 결과.
- **미회신 영향:** 측정은 미수신/미확인으로 남기고 모의 수치를 실제 판정으로 사용하지 않습니다.

### DB-02 B→C 액션 단위와 관측 상관 — P1

- **필요사항:** B 상세설계의 위치 m과 C가 요청한 B→C ROS 액션의 mm 표기가 충돌합니다. 이는 D 표시/TCP 경계의 mm 변환과 별개이며 B·C 협의 전 확정하지 않습니다.
- **요청 산출물:** B·C가 합의할 액션 단위·필드와 관측→목표→실행의 프레임 키·시각·세대·순번·유효성/폐기 규칙 및 예시. **제안 기한:** 11/20 통합 전.
- **D 제공:** GUI에 필요한 단위·식별자와 미확인 표시 사례.
- **미회신 영향:** 실제 목표·표시 값의 연동 정합을 검증할 수 없습니다.

## C에게 요청

### DC-01 분류 개정·도착과 집계 — P1

- **필요사항:** D가 TCP 부록 A를 출발점으로 개정안을 작성하고 C가 실행 의미·안전 조건을 검토·승인하며 B와 분류 의미를 협의합니다. 부록 A는 미승인이고 기존 TCP 1.1과 분리합니다. `START`·`STOP`·`RECOVER`·`GET_STATUS` 각각의 요청/응답, 슬롯 소유자·조회 대상, MOVE `command_id`와 분류 `sort_job_id`의 수명·소유·조회, `CANCEL`과 `STOP`, 수동 MOVE 거부, 중복·시간 제한·재접속을 포함합니다. STOP 접수와 정지 확인을 구분합니다.
- **요청 산출물:** 현재 C 지원 범위·검토 일정, 도착·격리·실패·중복 판정, 집계 범위·초기화와 스냅샷/후속 사건 포함 경계 및 예시. **제안 기한:** 11/17 범위 확인, 통합 전 합의 목표.
- **D 제공:** 버전·스키마·오류·시험 벡터 초안과 상태/집계 표시 사례. 승인 전 새 분류 명령은 실제 서버로 보내지 않습니다.
- **미회신 영향:** 내부 모의 및 기존 1.1 준비만 가능하며 실제 분류·집계 정합과 개정 승인 불가. 정상 상자 수량은 C가 도착을 확인한 부품만 반영하며 해제 요청·운반 완료·수동 MOVE REACHED만으로 세지 않습니다. C의 후속 격리 흐름은 실제 합의 기준을 따릅니다.

### DC-02 표시 경로와 카메라 대응 — P1

- **필요사항:** C→D 표시 연결은 명령·상태 TCP와 분리합니다. 링크 `raw`·`detect`·`center` 중 하나, 그리퍼 원본·고정 원본의 3영상과 결과·무효화 JSON을 표시합니다. A/B가 주석을 그린 영상에 D가 중복 합성하지 않습니다. D는 관전 영상 사용을 제안하며 `overview_cam/image`가 기존 고정 탑뷰 요구와 같은 센서·시점인지 A·C가 확인해야 합니다.
- **요청 산출물:** 영상 대응·센서/브리지 담당, C→D 연결·포트·직렬화·선택 접수/반영·영상 프로파일·프레임 매칭·유실/재접속과 예시. **제안 기한:** 11/17 초안, 11/20 전 합의 목표.
- **D 제공:** 채널 선택·화면 표시·단절/미수신 요구와 소비 예시.
- **미회신 영향:** 저장/모의 예제로만 준비하며 정식 3영상·결과 수신은 미완료입니다. 부록 B는 미승인입니다.

### DC-03 접속·복구와 공동 시험 — P1

- **필요사항:** Windows GUI↔WSL 서버의 실제 네트워크 방식·바인딩 및 복구 절차를 함께 확인합니다. 과거 C `0d8a9a3` NAT 시험에서 Windows `127.0.0.1:47090` GET_STATUS가 성공했으나 준비 상태는 `robot_ready:false`, `RECOVERING`이었습니다. `localhost` 약 2초 지연 원인은 IPv6 우선 추정일 뿐이며 WSL IP는 거부, mirrored는 미시험입니다. 최신 커밋의 절전·재시작·주소 변경 복구는 미검증입니다.
- **요청 산출물:** 사용할 접속 방식·바인딩·방화벽 조건, 시험 서버와 단절·재접속·중복 방지·상태/집계 재동기화 시나리오, 로그 소유자 및 실행 일정. **제안 기한:** 11/20 전 접속 확인, 11/23~25 장애 시험 목표.
- **D 제공:** 1.1과 승인 후 개정 시험을 나눈 절차·기대 결과·기록 양식 초안. 환경·커밋·서버·시나리오·요청 ID·기대/실제·판정·로그와 미실행 사유를 기록하고 각 OS 로그를 보존합니다.
- **미회신 영향:** 실제 접속·복구·분류 통합 검증 일정 보류. 설정 변경과 실제 시험은 이번 문서 작성에서 수행하지 않았습니다.

### DC-04 외형 인계·적용 확인 — P1

- **필요사항:** 로봇·그리퍼·벨트·상자·부품의 D 외형 인계와 C의 Gazebo 적용 확인을 맞춥니다. 정적 GUI 미리보기와 실제 로봇 상태를 구분합니다.
- **요청 산출물:** 현재 실행 자산 버전·경로, 링크·원점·축·단위와 적용 절차 및 C 확인 가능 일정. **제안 기한:** 11/17.
- **D 제공:** 편집 원본·실행 자산·출처·링크 매핑 등 확인 가능한 외형 인계 자료와 미확인 목록.
- **미회신 영향:** 인계 자료 준비만 가능하며 Gazebo 적용·스케일·정렬 확인은 미완료입니다.
