## 1. 좌표계·단위

| 항목 | 정의 |
| --- | --- |
| 모델 로컬 | SDF·메시 원점·축 그대로, 메시 단위 mm(SDF `scale 0.001`) |
| world | `p_w = R(rpy)·p_local + xyz`. R은 SDF 고정축 `Rz(yaw)·Ry(pitch)·Rx(roll)`(`scripts/gz_eval_scene.py rpy_to_matrix`), 단위 m |
| 카메라 | 표본 manifest `camera`: world → `link_cam_optical_frame`(t, q_xyzw), K(fx = fy = 1171.512, cx 640, cy 360), D = 0 |
| 픽셀 | `p_c = Rᵀ(p_w − t)`, `u = fx·x/z + cx`, `v = fy·y/z + cy`(오프셋 0. 메시 실루엣과 정답 마스크 대조에서 −0.5 px 규약보다 IoU가 높았음) |
| 각도 | 볼트 주축 θ는 world XY에서 +X 기준 반시계, **0~180° 주기**(B §5.4). 머리→끝 방향은 정답에 기록하되 운영 각도로 쓰지 않는다 |

## 2. 모델 기하 (메시에서 확인, `validation.json` model_dims 통과)

| 모델 | 기하(mm, 로컬) | 출처 |
| --- | --- | --- |
| BOLT_A `bolt_m6x12` / BOLT_B `bolt_m6x40` (ISO 4762) | 원점 = 머리·축 경계, +Z = 머리 쪽. 머리 z 0~6, r 5.0, 위·아래 모서리 면취 0.2, 머리 끝면에 육각 소켓(맞꼭짓점 r 2.887)이 z ≈ 1.18까지 파여 있음. 축 z −L~0, r 3.0, 끝 1 mm 면취(r 3 → 2). 나사산 모델링 없음. **머리 포함 총길이 6 + L = 18 / 46** | SDF 주석, STL 꼭짓점 |
| NUT `nut_m6` (ISO 4032) | 원점 = 아랫면 중심, +Z = 위, 두께 5.2. 육각 맞변 10, 맞꼭짓점 11.547(꼭짓점 방향 30° + 60k°). 위·아래 꼭짓점 면취 → 최상면(z 5.2)은 r 3.5~5.0의 **원형 고리**. 꼭짓점 모서리는 z 0.45~4.75에만 있음. 구멍 r 3.0, 양쪽 입구 면취 r 3.5 | SDF 주석, STL 꼭짓점 |

**v2 배치(정적):**
- 볼트 `rpy = (0, π/2, yaw)`: 로컬 +Z(머리 방향)가 world `(cos yaw, sin yaw, 0)` 수평으로 간다. 원점 z = 0.105이므로 **축 높이 105.0 mm**다. 머리 아래쪽은 벨트 윗면 100에 닿고, 축 아래쪽은 102로 벨트에서 2 mm 떠 있다(물리적으로 놓인 자세가 아님).
- 너트 `rpy = (0, 0, yaw)`: 원점 z = 0.1005이므로 **최상면 105.7 mm**다.
- B `plane_z` = 105 mm와 비교하면, 볼트 축 높이는 일치하고 너트 최상면은 0.7 mm 차이다.

**후보 비교**
- **(a) 총길이 중점**
  - 용도: 길이 판정과 같은 끝점 두 개로 정의되므로 끝점만 있으면 계산된다. SDF 질량 중심(inertial pose −3 / −17)과 같다.
  - 단점: 머리 쪽으로 치우쳐 축 위가 아닐 수 있다. BOLT_A에서는 −3 mm라 머리·축 경계에서 3 mm 떨어진 축 위다.
- **(b) 축 부분 중심**
  - 용도: 집게가 축(지름 6)을 잡는 경우의 파지점 후보다.
  - 단점: 머리·축 경계를 찾아야 한다. BOLT_A는 축이 12 mm로 짧다.
- **두 후보는 항상 축 방향으로 3.0 mm 떨어져 있다**(머리 높이의 절반). 제안 KPI 2 mm보다 크므로, 어느 쪽을 쓸지가 오차 판정에 직접 영향을 준다.
- **운영 파지점·최종 후보 선택은 B·C 계약이며 이번에 정하지 않는다.**

**가시성 (r1):**
- 축 점·선(`projection_only`)과 가상 축 점(`virtual_axis_point`)은 관측 가능성을 주장하지 않는다. 투영 위치만 정답이다.
- 면 위 점·면 경계는 다음 두 가지를 **보조 근거(`view_support`)**로만 기록한다.
  - 법선이 카메라를 향하는가
  - 투영 화소의 semantic 라벨이 자기 물체인가
- 같은 물체 안의 자기 가림(앞·뒷면, 소켓 안쪽)은 depth 근거가 없어 **`self_occlusion=unverified`, `visibility_verified=false`**다.
- 참고: 볼트 8사례 중 머리 끝 평면 법선이 카메라를 향한 것은 R02·R07이고, 나머지 6건은 축 끝면 법선이 카메라를 향한다. 가시성이 확인됐다는 뜻은 아니다.

**최상면·측면·면취 구분:**
- 최상면은 r 3.5~5.0의 원형 고리다.
- 그 바깥 꼭짓점 영역(r 5.0~5.774)은 면취면이다.
- 육각 꼭짓점 모서리는 z 4.75 아래에만 있다.
- 기존 전체 마스크는 측면을 포함한 실루엣이며, 최상면 외곽이 아니다.

**구멍:**
- 단일 외곽선(`calc_contour`)은 구멍을 표현하지 못한다.
- 면적을 평가할 때는 「외곽 기준 면적(구멍 포함)」인지 「고리 면적(구멍 제외)」인지를 명시해야 한다.
- 이번 자료는 두 경계를 따로 준다.

## 5. 현재 계약으로 표현되는가

| 부품 | 현 계약(`observed_face` + 단일 `calc_contour`) | 판단 |
| --- | --- | --- |
| 너트 | `observed_face="top_face"`, `calc_contour` = 최상면 바깥 경계(원 r 5.0 투영) | **자료형으로 표현 가능**(실제 RGB에서 그 경계를 추출할 수 있는지, 오차가 얼마인지는 검증하지 않음. 운영 유효화와 별개). 단, 구멍은 표현할 수 없다. B의 평면 높이(105)와 실제 최상면(105.7)이 0.7 mm 다르다 → B가 높이 값을 맞추거나 편차를 감수해야 한다(B 결정) |
| 볼트 | 머리 끝면·축 끝면 같은 평면은 있지만, **물체 전체를 덮는 하나의 수평 계산 평면은 없다**. 축선·끝점·기준점은 「면 윤곽」이 아니다 | **표현 불가.** 축·끝점에서 가짜 면 윤곽을 만들어 계약을 통과시키지 않는다. 별도 입력 계약(예: 축 양 끝점 px, 기준 높이, 위치 후보 종류)이 필요하다 → A·B 합의 대상 |
