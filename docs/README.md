TCP 세부 규약은 `protocol/TCP_프로토콜_명세서.md`를 기준으로 하며, 프로젝트 계획은 전체 흐름을 요약합니다. 분류 시작·정지·복구, 벨트·그리퍼·사람 제어 명령은 TCP 1.1에 넣지 않고 [TCP 명세서 부록 A](protocol/TCP_프로토콜_명세서.md)의 개정 제안(미승인)으로 다룹니다. 자동 분류 목표는 B→C ROS 액션입니다. 2026-11-11 재설계(Windows GUI·WSL A/B/C, 운전 모드 없음, START 분류)는 계획서 §2.1과 각 상세설계에 직접 반영했습니다(C 상세설계 §16.8·§16.11, B 상세설계 §15.4). 같은 날 별도 기능 설계 3개(그리퍼·로봇 실행, 컨베이어 분류, 사람 자세 제어)는 시스템 계획과 A/B/C/D 상세설계로 통합하고 삭제했습니다. 중복되는 상세 계약은 이 문서들 가운데 한 곳을 기준으로 두고 나머지는 링크로 연결합니다.
