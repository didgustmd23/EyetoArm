## 최초 실행→ACK 계측의 정의

시작은 D `StatusLink.execute()`가 유효한 사용자 요청을 수락한 시각, 끝은 같은 연결·첫 전송의 실제 첫 ACK 수신 시각이다. 같은 PC의 monotonic 시계를 사용하며 신선한 GET_STATUS 대기 시간도 포함한다. REACHED/로봇 실행 시간·서버 시각 차이와 다르다.

중복 ACK는 최초 값을 바꾸지 않는다. 재전송·재접속·ACK 없이 다른 상태로 수락을 추정한 경우에는 숫자를 만들지 않고 `—`와 사유를 표시한다. 성공률/위치오차는 정답·측정 근거 없이 계산하지 않는다. JSONL 지연 항목은 D 로컬 계측이며 TCP 패킷 필드를 바꾸지 않는다. API 세부와 시험 명령·최종 결과는 아래 검증 결과에 기록한다.
