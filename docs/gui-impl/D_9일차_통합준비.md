## 2. 실행 재현 절차

`dashboard-client` 폴더에서 실행한다. 저장소 밖으로 이 폴더만 복사해도 같다.

```powershell
conda activate eyetoarm
cd <저장소>\dashboard-client
$env:PYTHONPATH = (Resolve-Path .\src).Path

# 1) 환경만 점검(접속 없음). exit 0, "ok": true 가 나와야 한다
python -m eyetoarm.gui --env-only --json

# 2) 모의 화면(소켓 없음). 창을 닫으면 끝난다
python -m eyetoarm.gui.window --demo

# 3) 실제 연결(11/22, C 서버·relay 기동 뒤). 숫자 IP만 받는다
python -m eyetoarm.gui.window --host <C 서버 IP> --port 47090
#    영상 중계가 다른 PC 이면
python -m eyetoarm.gui.window --host <C IP> --port 47090 --view relay --view-host <영상 IP> --view-port 47092
```

제어 가능한 종료: 무인 확인은 `--shot <png> --shot-after <ms>`를 붙인다. 창을 띄우고 지정 시간 뒤 PNG를 저장한 다음 스스로 닫힌다. 화면이 없는 환경(`QT_QPA_PLATFORM=offscreen`)에서 한글이 □로 나오면 `QT_QPA_FONTDIR=C:/Windows/Fonts`를 지정한다. 이 설정은 화면 확인용이며 동작과 무관하다.

## 6. A 시험용 `TcpClient` 인계

- 위치: 저장소 `src/eyetoarm/tcp/client.py`의 `TcpClient(config, log, notify)`이다. GUI 배포본(`dashboard-client`)에는 들어 있지 않다. API는 [6일차 클라이언트 API](D_6일차_클라이언트_API.md)를 따른다.
  - 동기 함수: `connect()`, `snapshot()`.
  - 비동기 함수: `disconnect()`, `query_ready()`, `execute()`, `cancel()`.
  - 이벤트 루프는 A 도구가 소유한다. `connect()`는 루프 안에서 부르고, 종료 시 `disconnect()`를 기다린다.
- 지원 기준: TCP 1.1, Python 3.12. 부록 A 메시지는 미승인이므로 제공하지 않는다.
- 이번 회귀에서 `TcpClient` 관련 모듈(day1~3, entrypoints, client, day1_contract 등)은 모두 통과했다(§3).
- **D-07 미구현:** `notify()`나 `EventLog` 리스너에서 예외가 나면 통신 작업이 끝나 재접속이 멈출 수 있다. D가 결함을 확인했고([협업 요청 D-07 D 답신](../design/A담당_협업_요청_초안.md)), 코드 보완은 승인 대기 중이다.
  - **A 측 임시 조치:** 수정이 들어갈 때까지 A 도구가 `notify`·리스너를 예외를 내지 않도록 감싸서 쓴다(현재 A의 방식 유지). 콜백은 짧게 실행하고, 오래 걸리는 I/O는 콜백 밖에서 처리한다.
- A WSL 환경에서의 실제 호환, 접속 주소, API 안정 범위, 변경 알림 방법은 미확인이다(D-06 미결). 공동으로 확인한다.
